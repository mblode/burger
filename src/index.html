Burger

A fullscreen hamburger navigation menu in one stylesheet and one ES module, no dependencies. Press the button in the corner, or tab to it and hit Enter.

aria-expanded on the toggle is the only state there is, and the stylesheet derives the rest from it with :has(). The script does the one thing CSS cannot: the rest of the page goes inert while the menu is open, so Tab stays inside it. Escape closes and returns focus to the button.

Theming is redeclaring --burger-* custom properties. Install with npm install the-burger, or load both files from a CDN. The source is on GitHub.
